# Kinescope brand assets

The mark is a rounded screen on a short stand with a dot for its picture. The wordmark is
"kinescope" in lowercase Mona Sans, weight 650, width 108%, tracked -0.01em. The lockup is
the mark then the word, 12 px apart at nav size (34 px mark, 32 px type). `DESIGN.md` has
the full spec.

In the app the mark is an inline SVG (`app/js/ui/icons.js`) and the word is live text, so
the nav loads no image. Everything here is generated by `scripts/make-brand.py`.

| File | What | Used by |
| --- | --- | --- |
| `brand/mark.svg` | the mark, 34x34, `currentColor` | anywhere a symbol is needed |
| `brand/lockup-light.svg`, `brand/lockup-dark.svg` | mark and outlined wordmark, Lamplight (#F5F3EF) for dark backgrounds, Ember Ink (#151413) for light ones | |
| `brand/lockup-horizontal-{light,dark}-1920x640.png` | the lockup on a transparent canvas | the README's `<picture>` |
| `brand/wordmark-{light,dark}-1600x400.png` | the wordmark alone, transparent | |
| `icons/app-icon-{512,256,128,117}.png` | the app icon, rendered from `design/comps/icon.html` | |
| `tizen/icon-dev-117x117.png` | the 117x117 package icon, same as `app/icon.png` | `app/config.xml` |
| `splash/splash-1920x1080.png` | the launch splash, same as `app/img/splash.png`, rendered from `design/comps/splash.html` | `app/index.html` |

The icon is the mark in Lamplight on #101115 with a copper glow (#C9825B) baked in, so it
costs nothing at runtime. The splash is the nav lockup at 3.25x over the fixed warm
sign-in ambience.

## Regenerating

```sh
python3 -m venv /tmp/brand && /tmp/brand/bin/pip install fonttools brotli uharfbuzz pillow
/tmp/brand/bin/python scripts/make-brand.py
```

It needs Google Chrome for the PNG renders (`CHROME=` overrides the path) and starts
`design/serve.mjs` on port 8398 for the comps. It also writes `app/img/hero-mask.png`, the
raster fallback for Home's hero dissolve.

## Usage

- Lamplight lockup on dark backgrounds, Ember Ink on light ones. No other colours.
- Keep clear space of at least the mark's height around the lockup.
- The app is never published, so there are no Seller Office files.
